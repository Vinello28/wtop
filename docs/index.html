Key features

■Full hardware visualization

CPU (global + up to 128 per-core bars, model via CPUID), RAM & commit, disks & I/O throughput, GPU utilization & VRAM, network up/down, and an advanced sortable, filterable, killable process list.

■Sub-pixel braille graphics

Braille Unicode characters (U+2800–U+28FF) give a 2×4 sub-pixel resolution per cell — smooth, dense history curves identical to btop.

■Zero-WMI architecture

No WmiPrvSE.exe, no COM serialization overhead. Every metric comes from direct Win32 / NTDLL calls: NtQuerySystemInformation, GlobalMemoryStatusEx, GetIfTable2, native PDH.

■Isolated collector thread

A dedicated worker thread samples hardware state and hands immutable snapshots to the render thread — the UI never blocks and redraws at 60 FPS.

■Dual 24-bit TrueColor themes

Dark charcoal + neon accents, or an alabaster light theme for bright environments. Toggle instantly with t, saved to your config.

■Dynamic sampling rate

Adjust the refresh interval live with + / - — 250ms up to 5000ms — to trade responsiveness for even lower overhead.

The in-app auto-updater detects the running binary's architecture and always fetches the matching asset. The previous executable is deleted automatically once the update completes.

Keyboard shortcuts

KeyAction
Tab / Shift-TabSwitch the active (focused) panel
↑ / ↓ or k / jScroll the process list
PgUp / PgDnJump 10 processes up / down
Home / EndGo to the start / end of the process list
c / m / p / nSort processes by CPU / RAM / PID / Name
dReverse sort direction
/Real-time process search / filter
x or DeleteTerminate the selected process
tToggle theme (Dark ↔ Light)
+ / -Increase / decrease the sampling rate
uApply the update if a new version is available
gOpen the developer's GitHub profile
? or hShow the help window
q or EscQuit wtop / clear active filter

Build from source

git clone https://github.com/Vinello28/wtop.git
cd wtop
cargo build --release
.\target\release\wtop.exe

User configuration (theme, sampling rate, sort order) is saved automatically to %APPDATA%\wtop\config.json.
